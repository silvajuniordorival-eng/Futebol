Para compilar e rodar os arquivos pelo terminal integrado do VS Code, utilize os comandos abaixo:

    Compilar todos os arquivos .java da pasta:

    javac *.java

    Executar o arquivo principal (Main.java):

    java Main

    Outras formas de executar direto pelo VS Code

    Pelo botão de atalho: Abra o arquivo Main.java e clique no botão Run que aparece flutuando logo acima da linha public static void main(String[] args).

    Pelo atalho do teclado: Com o arquivo Main.java aberto, pressione Ctrl + F5 (Windows/Linux) ou Cmd + F5 (Mac) para executar sem depurar.
